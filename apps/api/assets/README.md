# Assets da API

## Logo do sindicato

`logo-sindicato.png` — usada no topo das declarações/autorizações em PDF.

## Assinatura da presidente

Coloque o arquivo `assinatura-presidente.png` neste diretório para que as declarações de convênio incluam a imagem da assinatura no PDF.

Sem o arquivo, o PDF ainda é gerado com nome, cargo e linha de assinatura.
